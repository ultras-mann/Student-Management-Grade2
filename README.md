# 📚 ប្រព័ន្ធបញ្ចូល និងគ្រប់គ្រងទិន្នន័យសិស្ស (Student Management System in Google Sheets)

ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងដោយប្រើប្រាស់ **Google Apps Script** (ផ្នែក Backend) និង **HTML/CSS/JavaScript** (ផ្នែក Frontend) ដែលអនុញ្ញាតឱ្យអ្នកប្រើប្រាស់អាចបញ្ចូល កែប្រែ លុប និងទាញយកទិន្នន័យភូមិសាស្ត្រ (ខេត្ត ស្រុក ឃុំ ភូមិ) របស់ខេត្តកំពង់ចាម បានយ៉ាងឆាប់រហ័ស និងមានរបៀបរៀបរយក្នុង Google Sheet។

## 🚀 មុខងារសំខាន់ៗ (Key Features)

*   **រៀបចំទម្រង់ស្វ័យប្រវត្តិ (Dynamic Dropdowns):** ធ្វើការផ្ទុកទិន្នន័យរាជធានី ខេត្ត ស្រុក ឃុំ និងភូមិ តាមលំដាប់លំដោយដោយស្វ័យប្រវត្តិ។
*   **បញ្ចូលទិន្នន័យថ្មី (Create):** បញ្ចូលព័ត៌មានសិស្សថ្មី រួមមាន នាមខ្លួន គោត្តនាម ទីតាំង និងលេខទូរស័ព្ទ ចូលទៅក្នុង Google Sheet។
*   **ជ្រើសរើសដើម្បីកែប្រែ (Update):** អាចជ្រើសរើសឈ្មោះសិស្សពីក្នុងបញ្ជីស្រាប់ ដើម្បីទាញយកទិន្នន័យមកកែប្រែឡើងវិញ។
*   **លុបទិន្នន័យ (Delete):** អាចលុបទិន្នន័យសិស្សចេញពីប្រព័ន្ធដោយសុវត្ថិភាព។
*   **ងាយស្រួលប្រើប្រាស់:** មានចំណុចប្រទាក់ (UI) ស្អាត រួមបញ្ចូលជាមួយ Font ភាសាខ្មែរ (Battambang) និង Icons ទំនើបៗ។

## 🛠️ បច្ចេកវិទ្យាដែលបានប្រើប្រាស់ (Tech Stack)

*   **Google Sheets:** ជាមូលដ្ឋានទិន្នន័យ (Database)។
*   **Google Apps Script (GAS):** សម្រាប់សរសេរកូដតភ្ជាប់រវាង Front-end និង Google Sheet ។
*   **HTML5 / CSS3 / JavaScript:** សម្រាប់បង្កើតទម្រង់បែបបទបញ្ចូលទិន្នន័យ (Web App / Modal Dialog)。
*   **Font Awesome & Google Fonts:** សម្រាប់តុបតែងកាដូបង្ហាញរូបតំណាង និងពុម្ពអក្សរ។

## ⚙️ របៀបដំឡើង និងដំណើរការ (Installation & Setup)

សូមអនុវត្តតាមជំហានខាងក្រោមដើម្បីយកកូដនេះទៅដំណើរការលើ Google Sheet របស់អ្នក៖

### ជំហានទី ១៖ រៀបចំ Google Sheet

1.  បង្កើត **Google Sheet** ថ្មីមួយ។
2.  ប្ដូរឈ្មោះ Sheet (Tab) ខាងក្រោមឱ្យចំឈ្មោះថា៖ `តារាងពិនិត្យឈ្មោះសិស្ស`
3.  នៅជួរទី ១០ (Row 10) ត្រូវប្រាកដថាជួរឈរ (Columns) របស់អ្នកត្រូវបានរៀបចំសម្រាប់ទទួលទិន្នន័យដូចខាងក្រោម៖

    *   **Column A:** លេខរៀង (ID)
    *   **Column B:** នាមខ្លួន (First Name)
    *   **Column C:** គោត្តនាម (Last Name)
    *   **Column D:** រាជធានី / ខេត្ត (Province)
    *   **Column E:** ស្រុក / ក្រុង / ខណ្ឌ (District)
    *   **Column F:** ឃុំ / សង្កាត់ (Commune)
    *   **Column G:** ភូមិ (Village)
    *   **Column H:** លេខទូរស័ព្ទ (Phone)
    *   **Column I:** ប្រព័ន្ធទូរស័ព្ទ (Network)

### ជំហានទី ២៖ បន្ថែម Google Apps Script

1.  នៅក្នុង Google Sheet សូមចុចពាក្យ **Extensions** > **Apps Script**。
2.  លុបកូដចាស់ទាំងអស់ចេញ រួចយកកូដពីឯកសារ **`Code.gs`** (ក្នុង Repository នេះ) ទៅ(Paste) ដាក់បញ្ចូលទីនោះ។
3.  ចុចប៊ូតុង **Save** (រូបថតឌីស ឬ `Ctrl + S`)。

### ជំហានទី ૩៖ បង្កើតទម្រង់ HTML

1.  នៅផ្នែក Apps Script Editor ត្រង់កន្លែង Files សូមចុចសញ្ញា **`+`** > **HTML file** ហើយដាក់ឈ្មោះថា **`Student_list`** (ប្រព័ន្ធនឹងបង្កើតជា `Student_list.html` ឱ្យស្វ័យប្រវត្តិ)。
2.  លុបកូដដែលមានស្រាប់ក្នុងឯកសារនោះចេញ រួចយកកូដ HTML ពីឯកសារ **`Student_list.html`** (ក្នុង Repository នេះ) ទៅ(Paste) ដាក់ចូល។
3.  ចុចប៊ូតុង **Save** ម្តងទៀត។

## ▶️ របៀបប្រើប្រាស់ (How to Run)

### 1. បើកតាម Google Sheet:

*   សូម Refresh (ផ្ទុកទំព័រឡើងវិញ) Google Sheet របស់អ្នក។ អ្នកនឹងឃើញម៉ឺនុយថ្មីមួយឈ្មោះថា **"📝 បញ្ចូលទិន្នន័យសិស្ស"** លេចឡើងនៅខាងលើ។
*   ចុចលើម៉ឺនុយនោះ ហើយជ្រើសរើស **"បើកទម្រង់បញ្ចូល (Open Form)"** ដើម្បីបង្ហាញផ្ទាំងបញ្ចូលទិន្នន័យ (Modal Dialog)។

### 2. ដាក់ឱ្យដំណើរការជា Web App (ທາງជ្រើសរើស):

*   នៅក្នុង Apps Script Editor សូមចុចពាក្យ **Deploy** > **New deployment**。
*   ជ្រើសរើសប្រភេទជា **Web app**。
*   កំណត់យក **Execute as:** `Me` និង **Who has access:** `Anyone`。
*   ចុច **Deploy** រួចយក Link ទៅបើកប្រើប្រាស់លើ Browser ជាការស្រេច។
